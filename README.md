# 🎯 Real-Time Object Detection

A real-time object detection application built with **Python** and **Flask REST API**, providing live video streaming and a web-based interface for detection results.

---

## ✨ Features
- 🔍 Real-time object detection
- 🎥 Live video stream via browser
- 🌐 Flask-based web application
- 🧪 Easy setup using Python virtual environment
- 🖥️ Access from any device on the local network

---

## 🛠️ Prerequisites
- Python **3.8 or higher**
- `pip`
- Camera or video source

---
